# theintelligencecommunity.art

Static link-tree landing page for **The Intelligence Community**, Mark Robert Henderson's electronic music project.

Single static `index.html`, no build step. Served via GitHub Pages at the custom domain `theintelligencecommunity.art` (see `CNAME`). Same setup as [astra-perdita-site](https://github.com/aphelionz/astra-perdita-site).

## Edit

Edit `index.html` and push to `main`. GitHub Pages redeploys automatically.

## Files

- `index.html`: the page
- `cover.jpg`: artist artwork
- `CNAME`: custom domain for GitHub Pages
- `74/`: unlisted pitch page for the 7/4 beat (`noindex`, linked from nowhere). It plays `74/tarantula.mp3`.
